# RANARP lampa biurkowa — источник 3D

- Товар: RANARP lampa biurkowa, kremowy, IKEA, арт. 302.313.15, 149 zł (ikea.com/pl, сняты 2026-11-15).
  https://www.ikea.com/pl/pl/p/ranarp-lampa-biurkowa-kremowy-30231315/
- 3D: официальная AR-модель IKEA `https://web-api.ikea.com/pl/pl/rotera/static/models/30231315-mini.glb`, скачана 2026-11-15.
- Габарит файла (Ш × В × Г): 18.8 × 53.4 × 55.2 см — реальный масштаб IKEA, не менялся.
- Лицензия: © Inter IKEA Systems B.V., публичной лицензии нет. Только личная визуализация квартиры владельца,
  модель отдельно не распространять и не публиковать.
- Обработка (агент кабинета, room3): Blender 5.2 — объединение, центр следа в 0, пол Y = 0, перед +Z, текстуры ≤ 1024,
  затем `gltf-transform meshopt`. `thumb.jpg` 256×256 — `tools/decor/thumb.py`.
- Правка: Повёрнута на 90° вокруг вертикали: плафон смотрит в +Z (к сидящему за столом). Только предмет, без источника света.
