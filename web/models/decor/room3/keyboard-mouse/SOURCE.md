# keyboard-mouse — универсальная клавиатура и мышь

- Источник: своя модель, сделана для этого проекта скриптом Blender (агент кабинета, 2026-11-15). Без бренда:
  IKEA компьютеров не продаёт, поэтому в каталоге это «универсальная модель».
- Лицензия: CC0 (общественное достояние).
- Габарит (Ш × В × Г): 55.1 × 3.3 × 13.0 см; метры, пол Y = 0, центр следа в 0, перед +Z, meshopt.
- Материалы: пластик/алюминий/тёмный экран без свечения (экран выключен, источников света нет).
- `thumb.jpg` — опция «монитор + клавиатура».
