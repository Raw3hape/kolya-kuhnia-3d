# books-shelf-mix60 — ряд книг (реквизит для полок, книги ≤ 25 см высотой, корешки в +Z)

- Источник: своя модель, сделана для этого проекта скриптом Blender (агент кабинета, 2026-11-15). Без бренда:
  IKEA компьютеров не продаёт, поэтому в каталоге это «универсальная модель».
- Лицензия: CC0 (общественное достояние).
- Габарит (Ш × В × Г): 59.0 × 25.0 × 17.7 см; метры, пол Y = 0, центр следа в 0, перед +Z, meshopt.
- Книги: один материал, цвет в вершинах (COLOR_0) — один вызов отрисовки на ряд.
