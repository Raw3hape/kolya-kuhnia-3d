# Постель для кровати 160×200 — условный реквизит

- Не товар: сделано процедурно в Blender 5.2 для этого проекта (агент спальни, room2), 2026-11-15.
  Скрипт-генератор жил в черновиках агента; перегенерация — заново по этому описанию.
- Лицензия: CC0 (своя работа), можно использовать где угодно.
- Состав: простыня #ddd5c8, одеяло #eeeae2 с отворотом 55 см, 2 подушки 64×46 #f1eee8, охристая подушка-валик #b8904f,
  терракотовый плед #b5744c поперёк изножья со свесами по бокам.
- Габарит (Ш × Г × В): 175.4 × 200.8 × 45.5 см (включая свесы пледа и подушки над матрасом).
- Начало координат: центр верха матраса 160×200; изножье в +Z. В кровати ставится на y = верх матраса + 1.65 см.
- Обработка: прорежено до 24 000 треуг., затем `gltf-transform meshopt`. `thumb.jpg` — `tools/decor/thumb.py`.
