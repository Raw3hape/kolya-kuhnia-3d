# Общий реквизит обстановки: книги, растения, вазы, рамки

Вещи без бренда, которыми агенты наполняют полки и углы всех зон. Каждая папка `<id>/`: `model.glb`
(метры, низ на Y = 0, центр следа в 0, перед +Z, meshopt), `thumb.jpg` 256×256, `SOURCE.md` (источник, автор,
лицензия, габарит). Только CC0 или своё.

Правила: существующую папку не перезаписывать, только переиспользовать; новый реквизит — новая папка со своим
`SOURCE.md`. Ставят реквизит части опций в `web/spec/decor/<zone>.json` (`"model": "models/decor/props/<id>/model.glb"`).

## Набор гостиной (`tools/decor/living/make_props.py`)

Размеры, след опоры (`foot`, горшок без листьев) и низ геометрии (`minY`: у свисающих плетей он ниже нуля) —
в `index.json`; раскладка полок читает их оттуда. Книги и эпипремнум — свои процедурные модели, растения, вазы и
рамки — Poly Haven, принты в рамах — свои (`make_prints.py`).
