# Festfloor microcement (GO! and Life)

Fetched 2026-11-15. Brand: Festfloor (PL). Recipes `festfloor_*` in `tools/textures.json` → "generated".

Microcement has no product face scans: it is applied on site. The texture is the CC0 ambientCG
concrete base named in each recipe, tinted to the colour sampled from Festfloor's official colour card.
The colour is approximate: the card is a lit render, so judge it against a physical sample.
