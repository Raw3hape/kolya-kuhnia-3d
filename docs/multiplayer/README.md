# Мультиплеер квартиры

Вход для продолжения работы: [план](PLAN.md), [архитектура и источники](ARCHITECTURE.md),
[сценарии входа и персонажи](EXPERIENCE.md). Первая проверка: [VALIDATION.md](VALIDATION.md).
Независимый аудит и повторные проверки: [INDEPENDENT-QA.md](INDEPENDENT-QA.md).
Внешние модели, жесты и их сетевой контракт: [AVATAR-ANIMATION.md](AVATAR-ANIMATION.md).

Требования: до 10 участников; оформление меняет только создатель; общие тела игроков,
охота, очки, двери, предметы в руках, попадания и разрушения всех отдельных предметов.
Поздний участник получает уже изменённую комнату. Токен хозяина не входит в ссылку приглашения.

Сайт — Vercel. Создатель комнаты исполняет общее ядро в отдельном Web Worker своего браузера.
Гости соединяются с ним по WebRTC; бесплатный PeerJS Cloud нужен только для установления связи.
Новый аккаунт, отдельный игровой сервер и платежи для этой схемы не требуются.

Хозяин держит вкладку открытой; при его выходе комната закрывается. Полная ссылка содержит
публичный ключ проверки хозяина, но не его закрытый ключ или токены участников.
Строгие NAT/firewall могут потребовать TURN: без ретранслятора нельзя гарантировать любую пару сетей.
Звук, громкость, камера и качество изображения — личные настройки. Выбранное видео и страницы общие.

`npm test` — контракты симуляции, разрешений, транспорта, содержимого и кодека.
`npm run build` — статический сайт. Источники и выбор технологий — в архитектурном документе.
