# Интерфейс конфигуратора

Как устроен экран и куда добавлять новое. Код: `web/js/ui.js` (панель, режимы, полоса), `web/js/help.js`
(справка), разметка и стили — `web/index.html`.

## Экран

- **Карточка слева сверху** — название, размеры, переключатель режимов «Проект · Прогулка (F) · Фото» и «?».
- **Панель справа** (на телефоне — шторка снизу) — всё, что меняется и настраивается.
- **Полоса режима внизу** (`#ctxbar` в `#hud-bottom`) — что можно сейчас: в «Проекте» ракурсы и «Двигать»,
  в прогулке и сидя — главные клавиши и «Выйти»/«Встать», в фото — прогресс, «Снимок PNG», «Выключить».
  Справа всегда «Графика: …» (ведёт в настройки). Пока догружается остальное — «Фоном: <что> · N %».
- **План** (`#kw-dock`, minimap.js) — слева от полосы; до 1100 px (планшет, телефон) — под карточкой.
- До 1100 px ракурсы в полосе сворачиваются в кнопку «Ракурс: …» с меню над ней, «Графика:» — только значение.

## Режимы

`body[data-mode]`: `design` · `arrange` (двигать мебель) · `walk` · `seat` · `photo`. Определяет ui.js
(`currentMode`) по `info.photo.running`, `seats.active`, `walk.active`, `info.furnEdit`; модули сообщают
о себе классами body (`kw-walking`, `ks-seated`, `khh-held`), ui.js на них подписан. Переключение —
`ui.setMode(id)` или кнопки режимов; Esc выходит.

## Вкладки по задачам

| Группа | Вкладки | Что там |
|---|---|---|
| Дизайн | Материалы, Кухня, Мебель, Свет | полы, стены, двери · фасады, остров · мебель, обстановка, расстановка · солнце, светильники |
| Опыт | Прогулка | прогулка и рост, сесть, оружие, охота |
| Результат | Экспорт | ссылка на вариант, фото-рендер, PNG и GLB |
| Настройки | шестерёнка | графика (по умолчанию «Эконом», строка о цене выбора), тема, справка, «показать подсказки снова» |

Список вкладок — `TABS` в ui.js (`group` рисует разделитель, `iconOnly` — только значок). Цифры 1–7 — по порядку.

## Как добавить

- **Раздел панели** — `addSection({ id, tab, title, order, controls })` из своего модуля; `tab` — id из `TABS`.
  Типы контролов перечислены в шапке ui.js.
- **Клавишу, жест, совет** — `addHelp({ mode, topic, keys, text, touch, brief, order })` (help.js) рядом с кодом,
  который их слушает. `brief: true` — попадёт в полосу режима (2–4 на режим). `touch: false` — нет на телефоне.
  Режимы для справки — `HELP_MODES`. В разделе панели те же строки — `{ type: 'help', topic }`.
  Писать клавиши текстом в readout нельзя: устареют.
- **Картинка из textures/ или models/** — через `fileUrl()` в ui.js (assetUrl из loading.js: `?v=<хеш папки>` из
  tools/build_static.mjs, чтобы после обновления файла не показывался старый кеш).
- **Светильник** — вариант в `LAMP_OPTIONS` (lamps.js) появится в «Светильниках» сам: off/on — переключатель,
  до трёх — сегменты, больше — чипы. Подпись — `LAMP_LABELS[key]` из lamps.js (пока его нет — таблица в ui.js).
- **Плавающая кнопка модуля** — `bottom: calc(var(--hud-bottom) + …)`: ui.js пишет высоту полосы в `:root`.
  Под карточкой заголовка на телефоне — `top: var(--kw-dock-top)` (пишет minimap.js).

## Загрузка

Событие `window` `kitchen:progress` `{ phase, loaded, total, done, weight, labels }` (шлёт loading.js, поля — в его шапке).
До `room` — заставка (index.html, свой скрипт): полоса по КБ, никогда не идёт назад (первые 15 % — «Программа 3D»,
модули), под ней две самые тяжёлые подписи из `labels`, «≈ X из Y МБ» и «ещё ~N с»; файлы кончились —
«Собираю сцену: свет и тени». С `room` можно работать, в полосе «Фоном: <что> · N %» (ui.js); `done` — убрать.
Подписи задают сами модули: `track(p, { label })`; списков в интерфейсе нет.
Без событий заставку снимает `ui.ready()` (main.js). Через 30 с — «дольше обычного», при ошибке — «Обновить страницу».
