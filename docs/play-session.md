# Непрерывная игра · 2026-11-16

Вход: [README](../README.md). Сеть: [GAMEPLAY](multiplayer/GAMEPLAY.md).

- `main.js`: после готовности первого вида включается прогулка, если она ещё
  не запущена. Сетевой вход по-прежнему ставит участника на позицию authority.
  «Проект» и «Фото» доступны по обычным кнопкам.
- `multiplayer/rules.js`: у всех четырёх видов оружия `infiniteReserve: true`.
  Общий `refillMagazine` наполняет магазин без уменьшения резерва, включая старое
  состояние с резервом 0. Сам магазин конечный; скорость, затвор и перезарядка прежние.
  В JSON/снимках остаются конечные числа. Клиент показывает `/ ∞` и доступную подпись.
- `hunt.js`: счёт накапливается до перезагрузки страницы. Нет двухминутного
  таймера, завершения раунда, окна имени/рекорда и фоновых запросов `/api/scores`.
  Компактный счётчик справа сверху виден в прогулке, скрыт в фото/экспорте.
- `multiplayer/session.js`: счётчик получает личные очки из снимка хозяина;
  каждый видит свой счёт. После выхода из комнаты восстанавливается одиночный счёт.
- Старые записи и API таблицы сохранены для совместимости; новый клиент их
  не читает, не изменяет и не показывает. Проверка/чистка имени API остаётся доступна.

Проверки: `npm test` — 73. Authority-тест реально расходует больше прежнего
запаса для каждого из четырёх оружий у хозяина и гостя, проверяет перезарядку
и позднее подключение. Отдельно проверено старое состояние с нулевым резервом.
`npm run build`, vendor integrity и `git diff --check` проходят.

В браузере: новый запуск в прогулке; `/ ∞`; одиночные очки растут без диалога;
хозяин и мобильный гость входят в прогулку и получают личный счётчик.
Конвейер нативной стрельбы и повторной перезарядки проверяется через реальные
клики/касания и WebRTC, без замены оружейных правил или транспорта.
