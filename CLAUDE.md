# Кухня-гостиная 3D — инструкция для агентов

Человеческое описание: `README.md`. Здесь только то, что нужно, чтобы продолжить работу.
`AGENTS.md` — симлинк на этот файл.

## Цель

Точная модель квартиры AA0304 (кухня-гостиная) для выбора материалов: быстро в браузере (three.js),
финальные кадры в Blender Cycles, дальше генерация в GPT-images по снимкам.

## Источник правды

- `web/spec/plan.generated.json` — стены, проёмы, балкон, выпуски света. Генерирует
  `tools/extract_plan.py` из `source/plan-AA0304.pdf`. Руками не править: править скрипт.
- `web/spec/kitchen.json` — кухонный ряд, остров, мойка, варка, радиатор. Авторский, править можно.
- `web/spec/views.json` — ракурсы камеры, общие для браузера и Blender.
- `web/spec/sofas.json` — реальные диваны IKEA PL под остров (размеры, цены, покрытия), их GLB в `web/models/sofas/`
  (вход: `web/models/sofas/README.md`, конвейер `tools/sofas/`).
- `web/js/catalog.js` — материалы, варианты для каждого слота, готовые сочетания. Код варианта хранит
  номер материала в группе: новые материалы только в конец группы.
- `tools/textures.json` → `generated` — рецепты полов (доска, ёлочка, плитка, микроцемент), их рисует
  `tools/make_floors.py`. `tools/real_tiles.json` — реальная плитка carrea.pl (фото лиц в `source/refs/tiles/`),
  её рисует тот же скрипт. У сгенерированных рядом `meta.json` с размером повтора.
- `web/spec/rugs.json` — ковры IKEA PL (размеры, цены PLN, ворс). Порядок = порядок в UI и в коде варианта:
  новые только в конец. Текстуры `web/textures/rugs/<id>/` + `SOURCE.md`, рисует `tools/make_rugs.py`
  из фото сверху; `whole: true` в meta = целый ковёр без повтора. Цены сняты 2026-11-15.

Оси: X вдоль оконной стены вправо, Z от окон вглубь квартиры, Y вверх, метры.
0 — внутренний угол кухни у стены с мойкой и окна. Blender: (x, y, z) → (x, −z, y).

## Ключевые размеры (сверены с PDF)

- Кухня-гостиная 617.1 × 368.0 см, у шахты глубина 374 см, потолок 2.64 м.
- Вентшахта 60 × 97 см у стены с мойкой (в эскизе это высокий белый короб 2.64 м).
- Окно кухни 120 × 131, подоконник 90 см, X 0.69–1.89. Балконная дверь 250 × 221, X 3.06–5.56,
  глухая часть слева 155 см.
- Кухонный ряд по эскизу: от шахты 60 + 60 (мойка) + 45 + 60 (варка) + 51.87 = 276.9 см = длина стены.
- Холодильник маленький, под столешницей, в крайнем модуле у шахты (`"fridge": true` в kitchen.json).
  Столешница идёт до конца ряда. Высокой колонны нет (уточнил владелец 2026-11-15).
- Межкомнатные проёмы 90 см (полотно 80), высота 2.05: комната 3, комната 2, ванная. Заданы в extract_plan.py.
- Остров 180 × 60 × 90. Проход 118 см и отступ 24 см от оконной стены оценены по видам SketchUp
  (`source/refs/sketchup-top.webp`), не измерены. Если владелец даст точные цифры, менять в `kitchen.json`.

## Код

- `web/index.html` пишется без doctype/head: так требует публикация Artifact.
  `tools/serve.py` локально добавляет тот же каркас.
- `main.js` — сборщик: состояние, код варианта, связь модулей, экспорт. Модули, каждый со своей шапкой-описанием:
  - `model.js` — стены, проёмы, кухня (UV в метрах); `materials.js` — текстуры; `catalog.js` — варианты.
  - `lighting.js` — солнце, небо (HDRI), свет окон и отражённый свет по комнатам: свет не протекает сквозь стены,
    экспозиция «как глаз». `lamps.js` — светильники по зонам. `site.js` — солнце над Варшавой по дате и времени,
    окружающие дома (`web/spec/site.json`, `tools/fetch_site.py`).
  - `cutaway.js` — изнутри прячет стену между камерой и точкой взгляда целиком; снаружи стены стоят,
    прячутся только потолок и этажи сверху. Спрятанное уходит на слой 1: не видно камере, но даёт тень и свет.
  - `render.js` — растр (качество fast/high/ultra) и фото-режим (трассировка пути, three-gpu-pathtracer).
    Метки: `userData.glass`, `passLight`, `shadowOnly`, у света `rasterOnly`.
  - `nav.js` — камера как в 3D-редакторе (колесо к курсору, WASD/QE, правая кнопка — сдвиг);
    `walk.js` — прогулка (F), рост 180, глаза 168, FOV 55; `minimap.js` — план с переходом по клику.
  - `furniture.js` + `spec/furniture.json` — диван, ТВ, тумба, ковёр, столик и редактор расстановки;
    `bath.js` — ванная; `ui.js` — панель (разделы регистрируются через `addSection`).
- Зоны: пол открытого пространства делится по X = `state.split` на floorA (вход и кухня) и floorB (гостиная),
  `buildFloors` пересобирает только пол. Стены красятся по граням: комната определяется по `rooms.*.rects`.
- Код варианта `#v3-…`: поля по порядку `SCHEMA_V3` в main.js; новые поля только в конец, старые ссылки (v1, v2,
  короткие v3) читаются. Сейчас хвост: …FURN_SCHEMA_2, LAMP_SCHEMA_ROOMS.
- `window.__kitchen` в консоли: `setState`, `goView`, `snapshot`, `exportGLB`, `pipe`, `lighting`, `furnEditor`
  для автоматических проверок.
- Проверка в браузере: встроенная панель Claude теряет WebGL после тяжёлой трассировки; надёжнее chrome-devtools MCP
  (`new_page` с `isolatedContext`). Перетаскивание стрелок редактора скриптом не проверить (нужна настоящая мышь).

## Команды

```bash
python3 tools/serve.py                                   # http://127.0.0.1:8765, POST /api/save -> exports/
uv run --with pymupdf tools/extract_plan.py              # план из PDF
uv run --with pillow tools/fetch_textures.py             # CC0-текстуры по tools/textures.json
uv run --with numpy --with pillow tools/make_procedural.py   # мрамор calacatta_rust + миниатюры
uv run --with numpy --with pillow tools/make_floors.py       # полы по рецептам и реальная плитка (готовое пропускает)
uv run --with numpy --with pillow tools/make_bath_tile.py    # уложенная плитка ванной 20×20
uv run --with numpy --with pillow tools/make_rugs.py <tmp> [id]   # ковры из фото IKEA, <tmp> потом удалить
uv run --with numpy --with pillow tools/make_bath_wall_tile.py    # плитка стен ванной 15×7,5
python3 tools/fetch_site.py                                  # дома вокруг и солнце -> web/spec/site.json
blender -b -P blender/render.py -- --glb exports/<file>.glb --view living --out renders/x.png \
  --date 2026-11-15 --time 13:00 --context --save blender/kitchen.blend
```

Новый материал: положить текстуру в `web/textures/<id>/` (color, normal, rough .jpg), добавить запись
в `tools/textures.json` и в `catalog.js`, затем пересобрать миниатюры (`make_procedural.py --thumbs`).
